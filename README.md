## Web Page Using HTML and CSS

This project is a static web page created using **HTML** and **CSS**. HTML is used to structure the content of the page, while CSS is applied to style the layout, colors, and typography, resulting in a clean and visually appealing design.

The project focuses on understanding the fundamentals of web development, including semantic HTML, basic CSS styling, and responsive page layout. It serves as a beginner-friendly project and a foundation for future improvements such as enhanced styling, additional pages, or interactive features.
